# Образовательный keylogger (демонстрация)

**Только для обучения!**  
Не используйте в реальной жизни без явного согласия владельца устройства.

## Возможности
- Логирование нажатий клавиш с поддержкой русской раскладки
- Отслеживание активного окна
- Мониторинг буфера обмена
- Скрытый запуск
- Управление через секретные комбинации (Ctrl+Shift+Alt+Q/K)
- Лог в UTF-8 (%APPDATA%\SystemMonitor\keysystem.log)

## Сборка (MinGW + CMake)

```bash
build.bat
# или
build.bat clean
build.bat run
