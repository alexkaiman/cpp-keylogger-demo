# Образовательный Keylogger (демонстрация) 🚀

**Только для обучения и изучения системного программирования!**  
Любое использование в реальных целях без явного согласия владельца устройства — **незаконно** и нарушает законодательство большинства стран.

![Keylogger Demo](https://github.com/alexkaiman/cpp-keylogger-demo/blob/main/screenshots/Screenshot_1.jpg)

## Возможности проекта ✨

- Логирование нажатий клавиш с **полной поддержкой русской раскладки** (включая фонетическую и стандартную ЙЦУКЕН)
- Отслеживание **активного окна** (заголовок окна в логе)
- Мониторинг **буфера обмена** (копирование текста через Ctrl+C / Ctrl+X / Ctrl+Insert)
- Полностью **скрытый режим** (без видимого окна)
- Управление через **секретные комбинации**:
  - `Ctrl + Shift + Alt + K` — показать консоль (для отладки)
  - `Ctrl + Shift + Alt + Q` — немедленно остановить программу
- Лог-файл в **UTF-8** с временными метками: `%APPDATA%\SystemMonitor\keysystem.log`
- Защита от повторного запуска через **mutex**
- Межпроцессное управление через **WM_COPYDATA** (`--stop`, `--show-log`, `--log-path`)
- Сборка через **MinGW + CMake** (одна команда `build.bat`)

## Требования

- Windows 10 / 11 (x64)
- MinGW-w64 (рекомендую winlibs UCRT x86_64-posix-seh)
- CMake 3.16+
